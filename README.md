# 📚 Library Management System

A PHP-based **Library Management System** designed to simplify and automate library operations such as managing books, students, issue/return records, and librarian activities.

This project helps libraries maintain records efficiently by replacing manual paperwork with a digital system.

---

## 🚀 Features

- 📖 Add new books
- 🗑️ Delete books
- ✏️ Update book details
- 👨‍🎓 Add student/member details
- 📕 Issue books to students
- 📗 Return books
- 🔍 Search books by title / ID / author
- 📊 View issued books records
- 👨‍💼 Librarian/Admin login
- 💾 Database integration with MySQL

## ⚙️ How It Works

The system allows the librarian to log in and manage all library operations through an easy-to-use graphical interface.

### Modules Included

### 1. Login Module
Secure login for admin/librarian access.

### 2. Book Management
- Add book details
- Update existing books
- Remove books
- Check availability

### 3. Student Management
- Add student details
- Manage member records

### 4. Book Issue Module
- Assign books to students
- Track issue date

### 5. Return Module
- Accept returned books
- Update database records

---

## 💡 Objective of the Project

The main objective of this project is to digitize the library workflow and reduce manual effort in handling books and records.

This system ensures:
- Faster record management
- Easy search and retrieval
- Better accuracy
- Reduced paperwork
- Email notifications
